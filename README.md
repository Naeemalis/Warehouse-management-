# NaeemSoft WMS

نظام إدارة مخزون محلي يعمل على Android باستخدام SQLite داخل الجهاز، مع واجهة عربية ودعم العمل دون اتصال.

## الحالة الحالية
بدأ تأسيس قاعدة البيانات وفق القرارات المعتمدة: قاعدة محلية، مخزن واحد في هذه المرحلة، وترحيل المخزون فقط عند اعتماد المستندات.

## ملفات المشروع
- `database/schema.sql`: الجداول والعلاقات والقيود والفهارس ومحفزات حماية المخزون.
- `docs/architecture.md`: نطاق الإصدار وتسلسل التنفيذ وثوابت حركة المخزون.

## ترتيب التنفيذ
قاعدة البيانات ← طبقة البيانات والمعاملات ← واجهات Android ← الاختبارات ← APK.

> لا تعتبر هذه المرحلة تطبيقاً نهائياً أو APK جاهزاً؛ إنها أساس قاعدة البيانات الذي ستُبنى عليه بقية المكونات.
