# NaeemSoft WMS

نظام إدارة مخزون محلي يعمل على Android باستخدام Flutter وSQLite داخل الجهاز، مع واجهة عربية والعمل دون اتصال.

## الحالة
- أساس Flutter وتطبيق Android المحلي.
- قاعدة SQLite بإصدار أولي ومفاتيح أجنبية مفعّلة.
- خدمات معاملات للاستلام والصرف ومرتجع المورد والجرد.
- اعتماد المستندات يرحّل الحركات داخل معاملة ذرية؛ المسودات لا تغيّر الرصيد.
- اختبارات أولية لتحويل وحدات الكمية، وفحص Flutter آلي عبر GitHub Actions.

## البنية
- `lib/src/data/wms_database.dart`: فتح قاعدة البيانات وإنشاء الجداول.
- `lib/src/services/stock_workflows.dart`: منطق اعتماد المستندات وحركات المخزون.
- `lib/src/screens/home_screen.dart`: لوحة البداية العربية.
- `database/schema.sql`: مرجع مخطط SQLite.
- `docs/architecture.md`: النطاق والثوابت المعمارية.

## التشغيل محلياً
يتطلب Flutter SDK:
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## حدود هذه المرحلة
هذه قاعدة Flutter ومعاملات أولية وليست إصداراً إنتاجياً. لا تزال شاشات إدخال المستندات، إدارة المستخدمين والصلاحيات، تقارير الأرصدة، اختبارات SQLite التكاملية، واختبار APK على جهاز Android مطلوبة قبل الاستخدام التشغيلي.
